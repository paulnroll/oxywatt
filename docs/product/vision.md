# Vision

Status: product intent supplied by owner, 2026-11-10; technical proposals await review.

OxyWatt — Open Cycling Performance Analytics — is an open-source, explainable cycling analytics product. First integration: Hammerhead Karoo 3. Local calculation and storage, no required account, subscription, cloud or telemetry.

The owner confirms power and HR sensors, normal-ride analysis, accumulated results, and a history chart. Existing Hammerhead activities and owner-supplied FIT files can support testing; access to them through the extension is not assumed. The supplied brief names Garmin HRM-600 and Wahoo KICKR CORE 2; individual sensor compatibility and indoor data equivalence need testing.

Success means automatically collecting supported rides, showing useful observed performance and defensible estimates when evidence permits, and explaining unavailable results. Smoothing must reduce noise without hiding conflicting evidence or converting invalid observations into valid estimates.

Long-term inspiration includes selected commercial training metrics. Compatibility with Garmin algorithms or their values is not a requirement or accuracy reference. The first release is not a clinical tool. Algorithm and device feasibility determine release readiness, not a promise to always display a number.

The owner has explicitly chosen a source-neutral Collector, independent FTP/VO₂max models, and whole-ride collection as the primary technical feasibility question.
